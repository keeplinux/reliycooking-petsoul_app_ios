> 版本：v1.0

## 1. 产品概述

### 1.1 产品定位
「宠物AI智能家居」是一款专为宠物主人设计的智能家居管理APP，通过软硬件结合的方式，实现**远程监控、智能操控、健康管理、AI互动**四大核心功能，让用户无论身处何地都能安心照顾家中爱宠。

### 1.2 目标用户
| 目标人群 | 特征描述 |
|---------|---------|
| 都市养宠人群 | 18-40岁，工作繁忙，白天无法陪宠物的上班族 |
| 多宠家庭 | 同时饲养2只及以上宠物的家庭 |
| 远程出差用户 | 经常出差/旅行，需要远程照看宠物 |
| 科学养宠用户 | 注重宠物健康饮食起居的精细化用户 |

### 1.3 用户痛点
- ❌ 上班担心宠物独自在家是否安全、是否吃喝正常
- ❌ 出差时无法实时了解宠物状态
- ❌ 家中无人时无法自动投喂、控制空调/灯光
- ❌ 宠物健康数据（体重、饮水、活动量）难以科学记录
- ❌ 传统智能家居产品功能单一，缺乏宠物专属适配

## 2. 产品核心功能

### 2.1 首页（宠物状态总览）
> 类似Apple HomeKit首页设计，卡片式布局

- **宠物实时状态卡片**：宠物照片、当前状态（休息/活动/进食）、在线状态
- **快捷操作区**：一键投喂、一键开灯、一键开空调
- **环境数据卡片**：室内温度、湿度、空气质量（PM2.5）、光线强度
- **今日概览**：步数、进食量、饮水量的环形进度展示
- **异常提醒**：高温预警、宠物长时间无活动、断网通知条

### 2.2 实时监控（视频/语音）
> 参考海康萤石云、小米摄像头的监控交互

- **高清视频流**：1080P实时画面，支持全屏、多角度切换（如有多个摄像头）
- **双向语音**：远程喊话、呼叫宠物
- **AI宠物识别**：
  - 自动识别宠物并抓拍精彩瞬间
  - 异常行为侦测（长时间吠叫、剧烈抽搐、倒地）
- **回放功能**：云端录像7天循环存储，支持时间轴拖动回看
- **截图/录像分享**：一键保存/分享到社交平台

### 2.3 智能喂食
> 参考小佩宠物App的喂食逻辑

- **定时投喂**：按日周设置多组喂食计划，如早晚各一次
- **手动投喂**：随时一触出粮，支持份量调节（10g/30g/50g）
- **剩余粮量监测**：粮桶余量百分条显示，低量提醒
- **喂食记录**：历史投喂日历、每次投喂时间/份量图表
- **食材管理**：记录当前粮种、保质期提醒、开封倒计时

### 2.4 智能环境控制
> 对接智能硬件设备（可通过HomeKit/Matter协议或自有云对接）

- **智能空调/暖风机**：自动温度调节（宠物适宜20-26℃），可设经常性策略
- **智能灯光**：昼夜自动开合，夜间柔光模式
- **新风/空气净化器**：联动空气质量传感器自动启停
- **饮用水循环**：监测水量、水质，缺水提醒
- **智能摄像头+感应器联动**：宠物进入某区域触发对应设备动作

### 2.5 健康管理
> 参考宠物医院App的健康档案逻辑

- **基础档案**：宠物体重、品种、年龄、绝育状态、疫苗记录
- **体征数据**：与项圈/手环等穿戴设备联动，记录心率、体温、活动量
- **健康报告**：周/月/年度活动量、进食量趋势分析图表
- **体重管理**：目标体重设定、超重/偏瘦提醒
- **疫苗/驱虫提醒**：到期推送提醒，支持添加接种记录
- **就医记录**：病历拍照归档（可选）

### 2.6 AI宠物助手（特色亮点）
> 本产品差异化功能

- **AI宠物识别百科**：拍照识别宠物品种、上传照片生成相似品种信息
- **AI行为解读**：通过摄像头画面智能分析宠物行为含义（如兴奋、紧张、不舒服）
- **AI喂养建议**：基于体重、品种、活动量生成每日科学喂食建议
- **语音助手**：「小宠，你现在在干什么？」→ AI返回宠物当前状态或抓拍照片
- **AI表情包/AR相机**：将宠物照片转化为3D虚拟形象、生成趣味表情包

### 2.7 消息中心
- 系统通知（设备离线、固件升级、异常检测）
- 宠物动态（AI抓拍推送、健康提醒）
- 互动消息（家人共享实时状态给对方）
- 消息分类管理、免打扰时段设置

### 2.8 我的（个人中心）
> 参考Apple HomeKit多用户管理 + 小米智能家居的账号体系

- **设备管理**：添加/删除/升级设备，设备兼容列表
- **家庭共享**：邀请家人共同管理，设置成员权限（管理员/普通成员）
- **账号安全**：手机号/微信/Apple ID登录、双重认证
- **云存储管理**：监控录像云存储套餐、用量查看
- **关于/帮助**：FAQ、客服、固件升级日志、隐私政策

## 3. 交互设计规范

### 3.1 设计风格
- **整体风格**：清爽明亮，圆角卡片式设计（iOS原生风格）
- **主色**：🐾 暖橙 #FF8C42 丨 辅助绿 #7ED9A5 丨 背景 #F5F6FA
- **字体**：iOS系统字体 SF Pro
- **图标**：线性图标，24px 标准尺寸
- **动效**：轻量级，页面切换采用 iOS 原生转场

### 3.2 信息架构
```
首页 (宠物状态总览)
├── 宠物状态卡片 (点击进入宠物详情)
├── 快捷操作区 (投喂/灯光/空调)
├── 环境数据卡片
└── 今日概览

监控
├── 实时画面
├── 回放
└── 事件相册

设备
├── 设备列表 (按房间分组)
├── 添加设备
└── 设备详情设置

健康
├── 宠物档案
├── 体重趋势
├── 饮食记录
├── 疫苗提醒

AI助手
├── 行为解读
├── 喂养建议
├── 拍照识别
└── 虚拟形象

消息
├── 系统通知

└── 家庭成员消息

我的
├── 设备管理
├── 家庭共享
├── 账号安全
├── 云存储
└── 设置
```

### 3.3 关键交互流程

**场景1：远程喂食**
```
首页 → 点击"投喂"按钮 → 弹窗确认份量 → 发送指令 → 设备执行 → 通知成功/生成投喂记录
```

**场景2：查看宠物实时状态**
```
首页 → 点击宠物卡片 → 进入宠物详情页 → 查看摄像头实时画面/活动量/喂食记录
```

**场景3：设置定时投喂计划**
```
设备 → 选择喂食器设备 → 定时计划 → 添加新计划（时间/份量/重复）→ 保存 → 生效
```

**场景4：接收异常预警**
```
系统检测宠物异常 → 推送通知 → 点击进入监控画面 → 查看实时回放 → 决定是否远程操作
```

## 4. 技术架构规划

### 4.1 系统架构 (iOS端)
```
┌─────────────────────────────────────┐
│         iOS App (SwiftUI/UIKit)      │
├─────────────────────────────────────┤
│  业务层：首页 / 监控 / 设备 / 健康   │
├─────────────────────────────────────┤
│  服务层：API请求 / WebSocket / 存储  │
├─────────────────────────────────────┤
│  数据层：CoreData / Keychain / 缓存  │
├─────────────────────────────────────┤
│  网络层：RESTful API + MQTT/WebSocket│
├─────────────────────────────────────┤
│  硬件对接：HomeKit / Matter / 自有云 │
└─────────────────────────────────────┘
```

### 4.2 硬件设备协议
| 协议类型 | 适用设备 | 说明 |
|---------|---------|------|
| HomeKit | 空调/灯光/门锁 | Apple原生，Siri联动 |
| Matter | 跨品牌设备 | 需iOS 16.1+ |
| 自有云API | 喂食器/摄像头 | 设备自有SDK |
| BLE | 穿戴设备(项圈等) | 近距离数据同步 |

### 4.3 后端服务
- **云端推送**：Apple Push Notification (APNs)
- **实时通信**：WebSocket 用于摄像头控制指令、设备状态实时同步
- **视频流**：HLS/RTSP 流媒体服务
- **AI服务**：云端AI识别接口（宠物行为分析、图像识别）

### 4.4 数据安全与隐私
- 视频流加密传输（TLS 1.3）
- 设备指令签名校验
- 隐私模式：摄像头物理遮蔽开关（可选硬件）
- 用户数据本地加密存储（Keychain）
- GDPR/国内《个人信息保护法》合规

## 6. 商业规划与运营

### 6.1 商业模式
- **硬件销售**：自有/联名智能硬件（喂食器、摄像头、项圈）
- **云服务订阅**：
  - 免费版：基础功能 + 云录像1天
  - 会员版（¥15/月）：7天云录像 + AI识别 + 健康报告
  - 家庭版（¥25/月）：支持3只宠物 + 5个成员 + 无限设备
- **增值服务**：AI精准投喂咨询、线上宠物医生（可选合作）

### 6.2 竞品分析

| 竞品 | 优势 | 本产品差异化 |
|------|------|-------------|
| 小米米家APP | 生态链完善、设备多 | 专注宠物场景深度 |
| 小佩宠物 | 硬件成熟、喂食专业 | AI行为解读 + 智能家居联动 |
| Petkit/小佩 | 海外口碑好 | 更本土化 + AI特色 |
| Pawbo 波奇 | 视频功能强 | 全面宠物健康管理 |
| **本产品** | **AI + 智能家居一体** | **差异化：AI助手 + 全屋联动** |

### 6.3 运营推广策略
- **初期**：宠物社群/KOL种草、B站/小红书养宠内容投放
- **中期**：与宠物用品电商品牌联名、硬件+App套装销售
- **后期**：宠物经济生态圈（宠物保险、宠物美容预约等合作）

## 7. 性能与兼容性要求

### 7.1 性能指标
| 指标 | 要求 |
|------|------|
| App启动时间 | ≤ 2秒（冷启动） |
| 首页加载 | ≤ 1秒 |
| 视频首帧 | ≤ 3秒 |
| 设备指令响应 | ≤ 1秒（本地）/ ≤ 3秒（云端） |
| 推送到达率 | ≥ 99% |
| 崩溃率 | ≤ 0.5% |
| App体积 | ≤ 150MB（含资源文件） |

### 7.2 兼容性
- **iOS版本**：支持 iOS 16.0+
- **设备**：iPhone SE（2代）及以上全系
- **屏幕适配**：刘海屏/灵动岛适配
- **网络**：WiFi / 4G / 5G 自适应
