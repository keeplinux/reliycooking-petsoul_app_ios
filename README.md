## 1. 产品概述

### 1.1 产品定位
「硅宠场域 PetSoul」APP是公司智能硬件**（硅基探针矩阵）**的官方管理平台。通过**宇宙叙事**的数字化呈现，将每只宠物视为一颗**温暖恒星**，用硅基探针采集其生命数据，构建独一无二的**数字孪生生命体**，让用户从「照料」升维为「恒星观测」。

### 1.2 核心价值主张
- **观测而非猜测**：持续数据采集替代主观判断，看见恒星的「健康亮度」
- **孪生而非记录**：不只是数据图表，而是拥有习惯、情绪与记忆的数字生命
- **守护而非监控**：以「陪伴守护」为叙事底色，而非冷冰冰的监控

### 1.3 目标用户
| 目标人群 | 特征描述 |
|---------|---------|
| 品牌早期用户 | 已购买/预约硅基探针（智能饮水舱）的首批体验者 |
| 都市养宠人群 | 18-40岁，工作繁忙，注重科学养宠的上班族 |
| 多宠家庭 | 同时饲养2只及以上宠物的家庭（多恒星观测） |
| 数据敏感用户 | 关注宠物健康数据、行为习惯的精细化用户 |
| 品牌追随者 | 认同宇宙叙事IP，关注探针矩阵扩展的忠实用户 |

### 1.4 用户痛点
- ❌ 出差/上班时无法知道宠物今天饮了多少次水、状态如何
- ❌ 现有智能硬件的App「设备工具感」太重，没有情感连接
- ❌ 分散的数据（饮水量、体重、活动）没有统一为「健康结论」
- ❌ 宠物长期行为变化无法被及时察觉（罕见病前兆）
- ❌ 硬件品牌缺乏统一的「产品星系」管理入口

## 3. 核心功能详细定义

### 3.1 🌌 宇宙首页（宠物数字孪生星系）

> **设计理念**：首页是一个可交互的「家园星系」——用户所有宠物恒星悬浮在深空星海中，每颗恒星周围环绕着已绑定的硅基探针轨道。这是APP的沉浸式入口。

#### 3.1.1 数字孪生星系总览
- **星空背景**：深空渐变「硅蓝」底色 + 呼吸光点粒子，营造星系沉浸感
- **宠物恒星**：每只宠物以「数字孪生形象」呈现——
  - 初始为宠物真实照片生成的**光晕头像恒星**
  - 随数据积累，光晕亮度、颜色、轨道运动代表其活跃度/健康亮度
  - 支持 2D/3D 切换（V2.0后支持3D可动孪生形象）
- **探针轨道**：每颗恒星周围有三道金色轨道圈——
  - 各位轨道代表已绑定的探针设备（饮水舱/喂食器/猫砂盆等）
  - 轨道上光点闪烁 = 探针在线且正在采集数据
- **多宠切换**：左右滑动导航星系，切换不同宠物恒星视图
- **恒星能量条**：类比「恒星亮度」展示今日综合健康指数
- **星系状态角标**：异常预警时恒星呈警示色（如不健康时变为暗红星）

#### 3.1.2 探针入口（核心交互）
- **点击探针轨道上的图标 → 进入该探针设备的专属详情页**
- **示例——「暖泉智能饮水舱」详情页**：
  - **设备状态**：在线/离线、水温（8°C冷星/45°C暖洋）、储水量（6L水星球）
  - **功能控制**：冷/暖水温切换、饮水模式（恒温模式/自然模式）
  - **实时数据**：今日饮水次数、单次饮水量、饮水时长、靠近频次
  - **历史数据**：按日/周/月查看饮水趋势折线图
  - **设备健康**：滤芯余量（星云渗透滤芯寿命）、水位警戒、清洁提醒
  - **监控功能**（仅限带摄像头的探针型号）：实时画面、双向语音、事件抓拍
- **多探针设备页均遵循统一卡片模板**：设备控制 → 数据观测 → 历史趋势 → 设备维护

#### 3.1.3 恒星观测速览（轻量数据卡片）
- **今日观测**：饮水 X 次 / 进食 X 次 / 靠近 X 次（环形进度）
- **温度环境**：环境温度/湿度（如探针带环境传感器）
- **异常通知条**：恒星异动预警横幅（如连续6小时未饮水）

#### 3.1.4 快捷语音唤起
- 长按首页星空 → 唤起「恒星观测」语音查询：
  - 「小宠今天喝了几次水？」→ 展示今日饮水数据
  - 「拍一张它的照片」→ 调用带摄像头探针抓拍

### 3.2 🔭 智能探针（硬件产品矩阵 + 设备管理）

> **设计理念**：探针是观测恒星的仪器。此板块分为「探针商城」与「已购探针」两大块。

#### 3.2.1 探针商城（产品线陈列）
> 参考 Apple Store 的产品陈列与小米有品的购买流程

- **商品陈列（当前产品线）**：
  | 探针型号 | 宇宙叙事命名 | 核心功能 |
  |---------|-------------|---------|
  | 暖泉智能饮水舱 | 暖泉星门探针 | 8°C冷星/45°C暖洋、6L水星球、饮水量/频次/时长观测 |
  | 星云渗透滤芯 | 星云渗透滤芯 | 多层毛细纤维、水电分离、水质净化 |
  | 硅基探针·数据入口 | 探针数据入口 | 记录饮水量、频次、停留时长—数据第一入口 |
- **商品详情页**：产品3D展示、宇宙叙事文案、参数规格表、用户评价
- **购买流程**：直接购买 / 预约探针（联系地球基地）
- **未来探针预告区**：「探针矩阵·即将抵达」——
  - 智能喂食器（观食探针）：定时投喂、食量观测、余量监测
  - 智能猫砂盆（归航探针）：如厕频率、排泄健康分析
  - 宠物项圈（星轨探针）：活动量、心率、定位
- **购买后引导**：购买/绑定成功 → 引导到「宇宙首页」添加为新探针轨道

#### 3.2.2 已购探针管理（我的探针矩阵）
- **探针列表**：按恒星（宠物）分组展示已绑定设备
- **设备信息**：型号、序列号、固件版本、WiFi连接状态
- **设备操作**：重命名（如「客厅饮水舱」）、设备图片、移除解绑
- **固件升级**：OTA升级推送、升级日志
- **添加设备**：扫码绑定新探针 → 选择绑定到哪只宠物恒星
- **设备权限**：摄像头/麦克风开关，默认关闭，随时一键停用（呼应「你授权才采集」）
- **离线管理**：设备离线提醒、日程安排（定时开启/关闭）

### 3.3 🪐 健康管理（恒星健康报告与洞察）

> **设计理念**：这是**结果性产品**板块——不是展示原始数据，而是将长期观测「分析提炼」为健康结论、报告与洞察。参考 Apple Health / 华为运动健康的报告体系。

#### 3.3.1 恒星健康报告（核心产物）
- **每日晨报**（每日9:00推送）：
  - 昨日饮水/进食/活动摘要 + 对比前日变化
  - 健康状态一句话：「今日恒星亮度正常✨」/「注意：近期饮水量下降12%」
- **周报告**：
  - 本周各项指标均值、与上周环比
  - 发现趋势 :「本周末饮水量明显低于平日」
  - 下周建议
- **月报告/年度报告**：
  - 综合健康评分（恒星亮度指数 0-100）
  - 各类数据分析图表（饮水/进食/体重/活动多维度）
  - 特殊事件回顾（异常日期的标注回顾）

#### 3.3.2 趋势分析（时间维度）
- **喝水趋势**：每日饮水量/频次的折线图、异常低谷标注
- **进食趋势**：食量变化曲线、食欲异常波动提示
- **活动趋势**：活跃时段分布、夜间活动侦测
- **体重曲线**：每周体重记录、BMI类健康指标

#### 3.3.3 行为洞察（AI分析）
- **行为节律图谱**：宠物日常行为节奏（如每天14:20活动峰值）→ 自动生成「恒星节律」图
- **异常行为预警**：
  - 连续6小时无饮水 ★
  - 饮水频次骤降 > 30%
  - 进食量骤减/骤增
  - 夜间异常活动增多
- **健康基线与偏差**：长期数据构建设备级别的「正常范围」，偏离即预警

#### 3.3.4 基础档案（健康基线建设）
- **宠物档案**：姓名、品种、年龄、体重、性别、绝育状态、基础疾病史
- **疫苗/驱虫提醒**：到期提醒、接种记录归档
- **就医记录**（V2.0）：病历照片、用药记录
- **健康基线设置**：参考体重、饮水量范围设定

### 3.5 🔭 星图观测（AR天文追踪）

> **设计理念**：将手机指向天空，用AR叠加的方式找到天上的行星——把「宠物是恒星」的宇宙叙事延展到**真实星空**。参考 Star Walk 2 / Sky Guide 的天文追踪体验。

#### 3.5.1 AR实时天空追踪
- **进入方式**：宇宙首页点击「星图观测」→ 打开相机AR界面（调用定位+指南针+陀螺仪）
- **核心体验**：
  - 手机指向天空任意方向，屏幕实时叠加显示该方向的天体信息
  - 识别并标注：太阳系八大行星、月亮、主要恒星与星座连线
  - 天体信息卡：名称、星等（亮度）、距地距离、升起/落下时间
- **行星方位指引**（对标 Star Walk 的「寻找天体」功能）：
  - 选定目标天体（如金星/木星/火星/土星）→ 屏幕边缘出现方向箭头 + 罗盘角度
  - 转动手机对准目标 → 中心锁定圈由红变绿 → 全屏天体档案展示
  - 支持搜索：输入「火星」「月球」直接定位导航
- **数据来源**：GPS定位 + 当前时间 → 实时计算天体方位角（Azimuth）与高度角（Altitude）

#### 3.5.2 寻找我的恒星（品牌特色功能）
> 将宇宙叙事推向高潮——你的宠物，真的有一颗只属于它的恒星。

- 每只宠物的数字孪生对应一颗「专属虚拟恒星」在 AR 天空中标记
- **恒星亮度联动健康**：宠物今日健康指数越高，其虚拟恒星越亮；健康异常时星色变暗红闪烁
- **观测互动**：
  - 对准宠物专属恒星 → 长按 → 「向恒星许愿」发送一句话（可附带宠物照片）
  - 生成「星轨明信片」：宠物照片 + 虚拟星位图 + 品牌元素 → 可分享社交平台
- **情感记忆**：历史观测位置生成「星轨轨迹图」，记录用户与宠物的每一次「星下相聚」

#### 3.5.3 天文观测日历
- **天文事件推送**：流星雨极大期、行星合月、火星冲日、超级月亮等自动提醒
- **观星推荐**：基于天气云量 + 月相 + 光污染指数给出「今晚适合观星」建议
- **观测记录**：打卡记录（「21:30 在阳台看到木星合照」）、观测相册
- **天文科普**：目标天体的趣味知识卡片（与宠物健康叙事关联）

#### 3.5.4 技术实现
| 技术点 | 说明 |
|-------|------|
| 定位与姿态 | GPS（CoreLocation）+ 指南针 + 陀螺仪（CoreMotion） |
| AR渲染 | ARKit + SceneKit 星空叠加层 |
| 天文计算 | 本地天文算法（行星轨道根数计算）+ 在线星历 API 校验 |
| 夜间模式 | 红色/暗色滤镜保护夜视能力 |
| 隐私 | 相机/定位仅在使用时调用，明确授权弹窗 |

## 4. 交互设计规范

### 4.1 视觉语言（宇宙叙事设计系统）
- **主视觉**：深空「硅蓝」#1A2238 为基底，暖橙色 #FF8C42 为恒星主光，金色 #F5C97B 为探针轨道光
- **辅助色**：星云紫 #7B6DFF 丨 生命绿 #7ED9A5 丨 警示红 #FF6B6B
- **字体**：iOS系统 SF Pro + 品牌英文 SILIFIELD
- **动效**：
  - 首页恒星呼吸光效（脉冲光晕）
  - 探针轨道光点流转动画
  - 页面过渡采用 iOS 原生转场 + 轻微星空粒子
- **图标**：线性图标，统一「星轨」设计语言
- **深色模式**：原生支持，深空底色天然融合

### 4.2 关键交互流程

**场景1：查看宠物（恒星）今日状态**
```
宇宙首页 → 点击恒星 → 恒星详情页（今日观测速览 + 各探针数据入口）
```

**场景2：查看饮水探针详情**
```
宇宙首页 → 点击饮水舱轨道图标 → 进入「暖泉智能饮水舱」页
  → 查看实时水温/水量/今日饮水次数
  → 切换「历史趋势」查看7天饮水折线图
  → 如设备带摄像头，切换到「监控」查看实时画面
```

**场景3：设置饮水模式（如切换恒温45°C）**
```
饮水舱详情页 → 点击「水温控制」→ 选择暖洋恒温45°C → 设备执行 → 状态更新
```

**场景4：在探针商城购买新探针**
```
智能探针 → 探针商城 → 选择「智能喂食器·观食探针」→ 查看详情 → 购买/预约
  → 到货后扫码添加 → 绑定到宠物恒星 → 新轨道出现在宇宙首页
```

**场景5：接收健康预警**
```
系统检测「连续6小时未饮水」→ 推送恒星异动预警 → 点击进入「健康管理·行为洞察」
  → 查看今日饮水趋势与异常标注 → 一键跳转饮水舱详情页确认设备状态
```

**场景6：查看每日晨报**
```
推送通知「今日恒星晨报」→ 进入健康管理 → 查看今日晨报卡片
  → 下拉查看「周报告」→ 分享报告给家人
```

**场景7：管理数据主权**
```
家长中心 → 数据主权中心 → 查看数据授权记录 → 导出数据/删除数据
```

**场景8：用AR找到天上的行星**
```
宇宙首页 → 点击「星图观测」→ 授权定位与相机 → 手机举向天空
  → 选择目标天体（如火星）→ 屏幕箭头 + 罗盘指引转动方向
  → 对准锁定（指示圈变绿）→ 查看火星方位/高度/距地距离 → 拍摄星轨明信片分享
```

**场景9：寻找我的宠物恒星**
```
宇宙首页 → 星图观测 → 点击「寻找我的恒星」→ 选择宠物（如"咪咪"）
  → AR天空中出现专属恒星标记 → 对准后查看今日恒星亮度（健康指数）
  → 长按「向恒星许愿」→ 发送一句话+宠物照片 → 生成星轨明信片分享家人
```

## 5. 技术架构规划

### 5.1 系统架构（iOS端）
```
┌─────────────────────────────────────┐
│        PetSoul iOS App (SwiftUI)     │
├─────────────────────────────────────┤
│  展示层：宇宙首页/探针/健康/家长     │
├─────────────────────────────────────┤
│  业务层：孪生渲染/设备控制/报告引擎  │
├─────────────────────────────────────┤
│  服务层：API/WebSocket/APNs推送/存储 │
├─────────────────────────────────────┤
│  数据层：CoreData/SwiftData/缓存     │
├─────────────────────────────────────┤
│  网络层：RESTful + MQTT/WebSocket    │
├─────────────────────────────────────┤
│  硬件协议：探针私有云协议 + BLE       │
└─────────────────────────────────────┘
```

### 5.2 关键技术点
| 技术点 | 说明 |
|-------|------|
| 数字孪生渲染 | SpriteKit（2D星系动画）/ SceneKit（3D V2.0） |
| 设备通信 | 私有云API（HTTP + WebSocket实时状态推送） |
| 视频流 | HLS直播（带摄像头探针型号） |
| 推送服务 | APNs（Observability推送）+ 本地通知兜底 |
| AI分析 | 云端AI引擎：行为识别、异常检测、健康报告生成 |
| 数据存储 | 本地CoreData缓存 + 云端同步，支持导出/删除 |
| 安全 | TLS 1.3、设备指令签名、Keychain密钥存储 |
