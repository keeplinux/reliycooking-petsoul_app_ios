# 硬件与产品待定清单

已确定：主控 ESP32-S3；原有 App 简约界面保留。以下均未定，不应据此直接生产 PCB 或采购外围器件。

| 项目 | 待提供/决定 | 影响 |
|---|---|---|
| 模块 | 完整丝印/料号、Flash/PSRAM 容量与接口、电源和天线方案 | 分区、媒体缓冲、可用 GPIO |
| 摄像头 | 传感器、JPEG 能力、DVP 接口、分辨率/帧率目标、夜视 | 相机驱动、带宽与存储 |
| TF | SDMMC/SPI、卡检测脚、容量/文件系统、录像策略 | 引脚与吞吐、热插拔 |
| 净水箱/污水箱/水盘 | 每路器件、接口电压、开关量或连续量、安装位置 | 驱动、标定、故障判断 |
| 温度 | 水温/环境探头型号、精度/范围、防水等级 | 外置接口与单位，不复用芯片温度 |
| RGB | 灯类型/数量、供电、驱动电平、默认亮度 | PWM/RMT、功耗、灯语实现 |
| 咪头 | 模拟/PDM/I2S、codec、采样格式、物理静音 | 音频输入与隐私指示 |
| 喇叭 | 功放、阻抗、功率、供电、音量限制 | 输出电路、功耗与回声 |
| 云端 | 域名、区域、MQTT/TLS、设备证书、账号认领、媒体网关 | 实际联网、访问控制与费用 |
| 本地控制 | 是否有泵/阀/消毒、故障安全状态 | 独立保护，未开放远程控制 |
| 生产 | 工厂灌装、调试口、恢复出厂、OTA 和售后换板 | 身份/密钥生命周期与分区 |

GPIO 分配表在确认以上硬件后统一补齐。尤其相机、TF、音频及 Flash/PSRAM 可能争用引脚和带宽，不能仅凭“ESP32-S3”型号给出可靠引脚表。
