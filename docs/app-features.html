2核心应用场景操作

场景 A · 首次绑定设备（扫码 + BLE，正常路径）

  1. 登录后进入 3D 首页，右上角点「扫码」。
  2. 扫码页点中间的取景框即开始扫描，识别到机身二维码后自动进入下一步（也可点「从相册选择二维码」）。
  3. 自动进入 BLE 连接 阶段：发现信号 → 建立 GATT 连接 → 读取设备信息，三步依次打勾。
  4. 连接成功后进入 WiFi 配网 页，填写 WiFi 名称与密码（密码至少 8 位）。
  5. 点「开始配网」→ 写入 WiFi 配置 → 设备连接路由器 → 云端绑定，三步完成。
  6. 结果页显示设备 SN、分配的 IP、配网方式、绑定时间，点「完成」。
  7. 回到首页，新设备以 3D 模型出现在星球上；点它进入设备详情看饮水数据。
演示建议填 Silifield-Office + 8 位以上密码。不要填以「5G」结尾的 WiFi 名称——设备固件无法加入 5GHz 频段，会直接走配网失败。

场景 B · 配网失败 → 自动提示保底配网（兜底路径）

对应「首次绑定无法扫码」「换了家里 WiFi 无法重新配网」「BLE 模块故障」三类现实问题。

  1. 点首页右上「扫码」，扫到任意一台设备。
  2. WiFi 名称填一个以 5G 结尾的网络（例如 Home-5G），密码填 8 位以上。
  3. 点「开始配网」→ 第三步「写入 WiFi 配置」失败，错误码 WIFI_UNSUPPORTED_BAND，失败页给出「重新填写 WiFi」。
  4. 同时底部自动弹出提示层：「试试保底配网」，说明可以让手机直连设备自己的 silifield 热点，App 会自动发现设备并重新下发 WiFi 配置，不需要机身二维码。
  5. 点「改用保底配网」→ 进入保底配网指引页，页面自动开始检测设备。
  6. 检测到设备后点「手动配网」→ 走「热点发现 → 会话校验 → WiFi 配网 → 绑定完成」四步，这次填 2.4GHz 网络即可成功。
  7. 回首页，设备已绑定；首页顶部也会出现「发现 1 台待配网设备」横幅（若该次未直接完成绑定）。
保底配网的常驻入口只保留在设置 →「配网遇到问题」里，对应「二维码丢失、一开始就没法扫码」这种连失败都无法触发的场景。 首页不再有任何保底配网按钮。

场景 C · 设备详情与数据

  1. 首页点击星球上的饮水机模型，进入设备详情。
  2. 顶部是在线状态条；下面依次是饮水数据可视化、今日饮水量 / 水量 / 水温 / 水质健康度四项指标。
  3. 「出水方式」可在持续流动 / 感应流动 / 不流动之间切换；下方可看探针运行状态与灯光模式。
  4. 「摄像头」区可切「实时 / 回放」，回放里选一段录像可播放，带进度条与时间显示。
  5. 如果点的是待配网设备，顶部会提示尚未配网并给出「立即配网」。

场景 D · 宠物数字形象 + 商城 + 设置

  1. 首页点击星球上的猫，进入「录入宠物数字形象」。
  2. 点「拍照」或「相册」选一张图，预览后点「上传并开始构建」；懒得选图就直接点「Demo 录入」。
  3. 回到首页，场景里会多出一只宠物。设备与宠物都会按球面角度错开摆放，不会重叠。
  4. 底部「探针」进商城，点任意商品进购买页，可跳转淘宝 / 京东。
  5. 底部「母舰」进设置：改通知开关、看设备 SN 与配网 WiFi、移除设备、退出登录（退出会同时清空设备列表）。

3配网失败码与兜底动作

失败一律由错误码驱动文案与可用动作，页面不散落字符串。错误码表在 src/provisioning.ts。

错误码 阶段 原型阶段如何触发 失败页动作
WIFI_UNSUPPORTED_BAND 配网写入 可自然触发：WiFi 名称以「5G」结尾 重新填写 WiFi + 自动弹出保底配网提示
BLE_NO_DEVICE BLE 发现 需固件返回，原型阶段不出现 重试连接 / 改用保底配网
BLE_CONNECT_TIMEOUT BLE 连接 需固件返回，原型阶段不出现 重试连接 / 改用保底配网
BLE_ALREADY_BOUND BLE 读取信息 需云端返回，原型阶段不出现 重试连接（提示原账号解绑或长按重置）
WIFI_WRONG_PASSWORD 设备连路由器 需固件返回，原型阶段不出现 重新填写 WiFi / 改用保底配网
DEVICE_NO_RESPONSE 绑定回执 需固件返回，原型阶段不出现 重试连接 / 改用保底配网
HOTSPOT_NOT_FOUND 热点发现 需真实探测，原型阶段不出现 重新检测（提示保持连接热点）
HOTSPOT_TOKEN_INVALID 热点校验 需固件返回，原型阶段不出现 重新检测

标「改用保底配网」的分支在扫码通道失败时会同时触发底部提示层，把兜底串成闭环，用户不需要自己去找入口。

4手机适配与人机边界

尺寸与安全区

  • viewport-fit=cover，配合 env(safe-area-inset-*) 留白
  • 顶栏与首页头部自动下移，不进入灵动岛 / 状态栏区域
  • 底部导航、页面底部与弹层避开 home 指示条
  • 页面高度用 h-dvh，跟随浏览器工具栏收缩
  • 非全面屏机型 env() 为 0，退化为常规留白，布局不回退

已经是真的 / 还是模拟的

  • 真：登录与登录态、二维码解析器（三种格式）、配网状态机、错误码体系、设备以 SN 为唯一键 upsert、设备列表持久化、3D 首页与交互
  • 模拟：相机解码、BLE 传输、保底热点探测（真机实现 probeHotspotGateway() 已写好但默认关闭）、饮水数据、云端绑定
  • 模拟能力统一收敛在 src/config.ts 的 simulateHardware 开关后，接真机时关掉即可，页面与状态机无需改动
