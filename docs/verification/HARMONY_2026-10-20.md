# HarmonyOS 移植验证记录

日期：2026-10-20。基线：iOS/Android 1.3.18；鸿蒙适配工程不改变 App 版本或已有页面。

## 已完成的工程工作

- 补齐 ArkTS Stage 工程、应用资源、原图标、权限声明与 ArkWeb 容器。
- 固定 HTTPS 虚拟源拦截 packaged rawfile，限制外部导航/资源，保留原有持久化源。
- 通过 JSON RPC 接入相机/照片选择、Scan Kit 和 BLE GATT；保留 AES-GCM 和分片协议。
- React 挂载前配置适配器；默认 Capacitor 路径继续服务 iOS/Android。
- 增加鸿蒙资源同步、三端哈希校验、工具探测和构建命令。
- 更新移植方案，移除“iOS已有APNs”和“同dist即可保证原生行为一致”等不准确结论。

## 验证证据

- `npm run build`：通过 TypeScript 与 Vite 构建。
- `npm run lint`：通过（共享 TS/TSX；不将 ESLint 当作 ArkTS 编译器）。
- `npm run verify:baseline`：51 个基准文件通过；main.tsx 仅新增启动适配，单独记录该非视觉差异及哈希。
- `npm run verify:water-protocol`：6 个样例及 11 个非法报文检查通过。
- `npm run sync` 和 `npm run verify:parity`：三端 17 个 Web 文件 SHA-256 完全匹配。
- src/views、src/components、src/index.css 和 src/platform/deviceProtocol.ts 相对本次起点无修改。
- 12 个 JSON/JSON5 工程与资源文件可解析；此检查不验证 SDK 字段、ArkTS 语法及 API 兼容性。
- Chromium（本机 Chrome）与 Playwright WebKit 共32个用例最终通过：整套回归先通过30项；新增启动注入用例因未等待自动账号读取完成而失败，补充等待条件后两内核各1项复验通过。没有修改页面/登录逻辑来绕过检查。
- 桥接使用受控测试端替代原生设备，不代表 Bluetooth Kit/相机实测。WebKit 浏览器不等于 iOS 真机，也不等于 ArkWeb。
