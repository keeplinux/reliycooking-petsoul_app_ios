## ArkWeb 运行实测

| 项目 | 实际结果与限制 |
|---|---|
| HAP 安装/启动 | Debug、Release 未签名包均在官方模拟器安装成功；EntryAbility 启动成功。覆盖安装后的旧 Ability 退出需要等待，不能只凭 aa start 返回成功认定页面已显示；最终冷启动已通过 |
| 登录/首页 | 原登录页可用；登录后原 Three.js 星球、宠物、饮水舱及导航正常渲染 |
| 导航 | 探针产品页、母舰设置页、扫码配网页可进入；系统 Back 从设置返回首页 |
| 持久化 | 强制结束进程并重新启动后保留登录与关闭的通知偏好；覆盖安装亦未丢失登录 |
| 安全源与加密 | Debug 构建通过 ArkWeb 官方 DevTools/CDP 测得 origin 为 https://app.silifield.local，isSecureContext=true；实际 AES-GCM 加密/解密返回原文 |
| IndexedDB | ArkWeb 创建并打开测试数据库成功；不能据此宣称全部媒体数据已完成重启验收 |
| 宠物录入 | 四视图模型、原表单与采集弹层显示。测试通过 HomeScene 现有 onCatClick 回调进入该页，未将此认定为3D射线点击验收 |
| 视口/输入 | ArkWeb 测得 innerWidth=407、visualViewport.scale=1、无横向溢出；通过 CDP Input.insertText 输入测试名字后仍一致。系统输入面板出现时高度缩至约335，退出后恢复620，宽度/缩放未变。模拟器输入法首次协议未接受，不能把该结果当作完整 IME/中文联想输入验收 |
| 图片选择 | 原 file input 可调起系统“所有图片”，取消后返回；Release 包从扫码页打开相册亦通过 |
| 视频选择 | 原 video/* file input 可调起系统“所有视频”，取消后返回；模拟器图库无测试视频，实际解码、时长读取与恢复仍待验证 |
| API13 文件类型兼容 | 原生 getAcceptType 会把 image/*、video/* 展开为扩展名列表。已修复 MIME/扩展名两种格式识别，按 capture 区分系统相机与图库，不把视频强制当作图片选择 |
| 系统扫码 | 实际原生调用返回 Emulator is not supported.，原页面展示失败并可重试；未伪造二维码或连接成功 |
| 系统相机 | CameraPicker 在本模拟器未返回有效结果，已处理空结果并释放临时文件。真机拍摄、权限拒绝与取消路径需复验 |
| BLE/真实配网 | 未使用模拟器结果冒充实际设备连接；NEXT 手机与兼容水机固件未就绪，待真机联调 |

Debug 调试没有新增业务 RPC、外部网页权限或任意文件接口。拍摄输出存入应用缓存，供 FileReader 使用完毕后随宿主清理；不自动写入用户图库。视频保留原共享页面处理。

## NEXT 真机待办

1. 合法开发签名、目标设备 profile、签名 HAP 安装与冷启动；HarmonyOS 4.2 不适用。
2. 相机照片、方向/HEIF、图库 URI/FileReader、视频解码与持久化、扫码取消/拒绝/真实 QR。
3. BLE 权限、设备选择、GATT 通知/写入、加密分片、真实水机配网及回执、断线/超时/后台恢复。
4. 真机中文输入法、键盘收起后的布局、多种系统字号、安全区、返回手势、WebGL 长时运行与内存。
5. 逐页面对比实际 iPhone 与 NEXT；共享资源一致不能代替系统弹窗、字体渲染、GPU与原生能力一致。

当前水机 Rust 固件尚未实现 App BLE 服务，本次不能声称完成水机端到端联调。云登录、真实推送、传感器后端仍沿用 iOS 当前未实现边界；现有 iPhone 沙箱数据不会自动迁移到鸿蒙。
